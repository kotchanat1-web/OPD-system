# ระบบบริหารงานเวชระเบียน OPD คลินิกเวชกรรมนครสวรรค์เฮลท์แคร์
### (Vercel Cloud Ready, Mobile Responsive & Smart Card Automation — เวอร์ชัน 6.0)

ระบบ Web Application สำหรับงานเวชระเบียนผู้ป่วยนอก (OPD) ครบวงจร พร้อมฐานข้อมูลผู้ป่วยชุดล่าสุด (683 ราย) และประวัติการตรวจ (1,118 รายการ) รองรับการใช้งานผ่าน Vercel / Cloud, อุปกรณ์เคลื่อนที่ iPhone/สมาร์ทโฟน และการอ่านบัตรประชาชน Smart Card ผ่าน WebSocket บนคอมพิวเตอร์ทุกเครื่อง

---

## 🚀 การใช้งานบน Vercel / Cloud และคอมพิวเตอร์เครื่องอื่น

เมื่อ Deploy ขึ้น **Vercel** สามารถเปิดใช้งานผ่าน URL `https://...vercel.app` ได้จากทุกอุปกรณ์ (คอมพิวเตอร์, iPad, iPhone):

### 1. การใช้งานเครื่องอ่านบัตรประชาชนบนคอมพิวเตอร์เครื่องอื่น (Client PCs):
เนื่องจากเว็บเบราว์เซอร์บน HTTPS/Cloud ไม่สามารถเข้าถึงพอร์ต USB ได้โดยตรงหากไม่มีตัวเชื่อมต่อ:
1. คัดลอกไฟล์ **`CardReader.exe`** และ **`เปิดระบบอ่านบัตร_สำหรับคอมเครื่องอื่น.bat`** ไปไว้ที่คอมพิวเตอร์เครื่องที่ต่อเครื่องอ่านบัตร
2. เสียบสาย USB เครื่องอ่านบัตรประชาชน
3. ดับเบิ้ลคลิกไฟล์ **`เปิดระบบอ่านบัตร_สำหรับคอมเครื่องอื่น.bat`**
4. เปิดหน้าเว็บระบบบน Vercel และเสียบบัตรประชาชน ระบบจะตรวจจับและดึงข้อมูลอัตโนมัติทันทีผ่าน WebSocket (`ws://127.0.0.1:8181`) โดยไม่มีปัญหา Mixed Content บล็อก!

> **💡 เคล็ดลับ:** ดับเบิ้ลคลิกไฟล์ `ติดตั้ง_เริ่มอ่านบัตรอัตโนมัติเมื่อเปิดคอม.bat` บนเครื่องนั้น เพื่อให้โปรแกรมอ่านบัตรเริ่มทำงานอัตโนมัติทุกครั้งที่เปิดคอม

---

## 📂 ศูนย์จัดการและอัปเดตฐานข้อมูล (In-App Live Data Update)

ในแท็บ **"สำรอง / Cloud Sync"** มีระบบอัปเดตข้อมูลสด:
1. **อัปเดตไฟล์ HTML ทันที:** สามารถลากวางไฟล์ `เวชระเบียน OPD.html` หรือ `AN visit OPD.html` เพื่ออัปเดตผู้ป่วยและ Visit ใหม่ได้โดยตรงจากหน้าเว็บ แม้เปิดใช้งานจาก Vercel
2. **ปุ่มซิงค์ข้อมูลชุดล่าสุด (Sync to Latest System Seed):** รีโหลดฐานข้อมูลเริ่มต้นล่าสุดของระบบ (683 ผู้ป่วย, 1,118 Visits) ได้ใน 1 คลิก
3. **ส่งออก / นำเข้าไฟล์สำรอง (JSON Backup):** สำรองข้อมูลทั้งหมดของคลินิกได้ตลอดเวลา

---

## 📱 การใช้งานบน iPhone / สมาร์ทโฟน

- **แถบเมนูพับเก็บได้ (Off-canvas Drawer):** กดปุ่ม Hamburger Menu (☰) ที่มุมบนซ้าย เพื่อเปิด-ปิดแถบเมนูหลักอย่างราบรื่น
- **Mobile Bottom Navigation:** แถบเมนูลัด 5 ปุ่มด้านล่างหน้าจอ เข้าถึง หน้าหลัก, เวชระเบียน, ตรวจรักษา OPD, แสกนบัตร และเมนูอื่น ได้ด้วยมือเดียว
- **Touch-Friendly Layout:** ตารางข้อมูลเลื่อนแนวนอนได้สะดวก ฟอร์มและปุ่มกดขนาดเหมาะสม ไม่เกิดการซูมผิดปกติบน Safari/iOS

---

## 💳 การเปิดระบบใช้งานบนคอมพิวเตอร์หลัก (Local)

1. **เปิดทั้งระบบ + เครื่องอ่านบัตร:** ดับเบิ้ลคลิก `เปิดระบบOPD.bat`
2. **เปิดเฉพาะบริการอ่านบัตร:** ดับเบิ้ลคลิก `start-card-reader.bat` หรือ `เปิดระบบอ่านบัตร_สำหรับคอมเครื่องอื่น.bat`
