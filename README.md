# ระบบบริหารงานเวชระเบียน OPD คลินิกเวชกรรมนครสวรรค์เฮลท์แคร์
### (Smart Card Auto-Detection & Full Clinic Automation — เวอร์ชัน 5.4)

ระบบ Web Application สำหรับงานเวชระเบียนผู้ป่วยนอก (OPD) พร้อมระบบอ่านบัตรประชาชน Smart Card อัตโนมัติและระบบกรอง **ผู้ป่วยนัดหมายเฉพาะวันนี้ (Today's Appointments)** บน Dashboard อย่างแม่นยำ

---

## 💳 การใช้งานระบบอ่านบัตรประชาชน (Smart Card Reader)

1. **วิธีเปิดระบบแบบง่ายที่สุด (แนะนำ):**
   - ดับเบิ้ลคลิกไฟล์ `เปิดระบบOPD.bat` 
   - ระบบจะเริ่ม Bridge อ่านบัตรในพื้นหลังและเปิดหน้าเว็บ OPD ให้ทันทีโดยอัตโนมัติ

2. **หากต้องการเปิดเฉพาะบริการอ่านบัตร:**
   - ดับเบิ้ลคลิกไฟล์ `start-card-reader.bat`
   - ระบบจะตรวจหา Node.js หรือสลับใช้ `CardReader.exe --server` อัตโนมัติ (พอร์ต 8181)

3. **การเสียบบัตรประชาชนในหน้าเว็บ:**
   - กดปุ่ม **"⚡ เสียบ Visit ด้วยบัตรประชาชน"**
   - เมื่อขึ้นสถานะสีเขียว *"เครื่องอ่านบัตรพร้อมใช้งาน"* ให้**เสียบบัตรประชาชนเข้าช่องอ่าน**
   - ระบบจะตรวจจับและดึงข้อมูลอัตโนมัติทันที พร้อมเสียงแจ้งเตือนและปุ่มเปิด Visit/ออก AN ด่วน!

---

## 📅 การปรับปรุงระบบนัดหมายบน Dashboard:
- ตาราง **"ผู้ป่วยนัดหมายวันนี้ (Today's Appointments)"** บนหน้า Dashboard จะ **กรองและแสดงเฉพาะผู้ป่วยที่มีวันนัดหมายตรงกับวันที่ปัจจุบัน (วันนี้) เท่านั้น**
- หากไม่มีคิวนัดหมายในวันดังกล่าว ระบบจะแสดงข้อความแจ้งเตือนที่ชัดเจน เช่น `ไม่มีผู้ป่วยนัดหมายสำหรับวันนี้ (DD/MM/YYYY)`
- รายการนัดหมายทั้งหมดในอนาคต/อดีต สามารถดูและจัดการได้ครบถ้วนในแท็บ **"ระบบนัดหมายผู้ป่วย"**
